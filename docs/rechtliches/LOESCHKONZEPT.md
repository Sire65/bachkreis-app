# Löschkonzept – Muster

Grundsatz: Daten werden gelöscht, sobald sie für den Zweck nicht mehr gebraucht werden und keine gesetzliche Aufbewahrungsfrist gilt.
Was die App **automatisch** löscht, ist mit ⚙️ markiert; der Rest wird von Leitung/Vorstand einmal im Jahr (nach dem Schuljahr, August) geprüft.

| Daten | Frist | Wie |
|---|---|---|
| Anklopfen / Anrufvermittlung | 7 Tage / 2 Tage | ⚙️ automatisch (Server-Aufräumen) |
| Versand-Protokolle (E-Mail/Push) | 30 Tage | ⚙️ automatisch |
| Änderungsprotokoll | 12 Monate | ⚙️ automatisch |
| Notfall-Gesundheitsangaben | Ablaufdatum (spätestens nach der Fahrt / dem Schuljahr) | ⚙️ automatisch |
| Fehlerberichte (ohne Inhalte) | 90 Tage | ⚙️ automatisch |
| Chats und Anhänge | bis die Person sie löscht; bei Austritt nach 1 Jahr | Leitung beim Jahresabschluss |
| Mitgliedsdaten Ausgetretener | 1 Jahr nach Austritt, dann löschen oder auf „Ehemalige“ (Name, Instrument, Jahre) reduzieren – nur mit Einverständnis | Leitung, PC-Verwaltung |
| Leihverträge | Vertragsende + 3 Jahre (Verjährung) | Instrumentenwart |
| Kasse, Spenden, Erstattungen | 10 Jahre | Vorstand/Kasse |
| Zustimmungs-Nachweis | Mitgliedschaft + 3 Jahre | Vorstand |
| Fotos | bis Widerruf der Einwilligung oder Ende der Mitgliedschaft, öffentliche Fotos bis Widerruf | Leitung |
| Sicherungskopien | rollierend 30 Tage (Neon), 90 Tage (Backblaze) | ⚙️ automatisch durch Überschreiben |

Löschwünsche einzelner Personen (Art. 17): formlos an den Vorstand; Erledigung innerhalb eines Monats, Vermerk im Vorstandsordner.
Kinderdaten haben Vorrang: Auf Wunsch der Eltern werden sie sofort gelöscht, sofern keine gesetzliche Frist entgegensteht.
